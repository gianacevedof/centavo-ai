# Centavo AI

> An intelligent, reliable financial tracking platform combining natural-language expense logging with deterministic SQL accounting.

**Course:** CIS 2910C – IT Capstone (Fall 2026)  
**Institution:** Valencia College  

---

## 📌 Project Overview

Many individuals and small business owners struggle with manual financial organization and spreadsheets. Centavo AI solves this problem by using a strict separation of concerns:
- **Natural-Language Input:** The Google Gemini API reads conversational user inputs (e.g., *"Bought groceries for $62 using checking"*) and extracts structured data.
- **Deterministic Accounting:** All math, account balance updates, category budget limits, and goal tracking are handled strictly by backend code and a relational MySQL database.

---
